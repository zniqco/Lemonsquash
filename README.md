A simple app launcher for Windows.

---

Press **Alt + Space** to open Lemonsquash and start typing.

- Find and launch apps.
- Calculate expressions and copy results.
- Search Google with suggestions.
- Run commands.

Lemonsquash started in 2016 as a hand-coded C# project.<br>
In 2026, it was completely rewritten in C++ using Codex.<br>
(Some code is still written by hand)
